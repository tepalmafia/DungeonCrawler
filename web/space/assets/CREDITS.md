# 그림 출처

이 폴더에 넣는 파일마다 **출처와 라이선스**를 여기 적습니다.
직접 그리신 것도 「직접 그림」이라고 적습니다 — **아무것도 안 적힌 것과
구분이 안 되면 3년 뒤에 그 파일은 못 쓰는 파일이 됩니다**
(`docs/space/RELEASE.md` §4).

AI 로 만든 것도 반드시 적습니다. 상점 심사에서 묻는 곳이 늘고 있고,
소급해서는 못 찾습니다.

형식:

```
<파일명>   <출처> (<라이선스>)   <링크 또는 메모>
```

_(아직 없음 — 규격은 `web/space/js/core/asset-table.js`)_

# 넣는 법

## 1. 어디에 떨어뜨리나

```
web/space/assets/surf/hull_wall.png
web/space/assets/sky/deep.png
...
```

폴더 이름까지가 파일 이름입니다 (`surf/hull_wall` → `surf/hull_wall.png`).
`.png` · `.jpg` · `.webp` 다 됩니다. 하늘처럼 큰 것은 `.jpg` 가 낫습니다.

## 2. 확인

```
python3 tools/serve.py 8137     →  http://127.0.0.1:8137/space/
```

브라우저 콘솔이 `[assets] 4/10장 — 적용` 이라고 찍습니다.
**이름이 틀리면 그 자리에서 말합니다** — 조용히 무시하지 않습니다.

## 3. 배포 전에 한 번

```
node tools/assets.js space --write
```

GitHub Pages 는 폴더를 훑어 줄 사람이 없어서 목록 파일이 필요합니다.
**이걸 빠뜨리면 로컬에선 나오고 배포판에선 안 나옵니다.**

# 무엇이 필요한가 — 화면 면적 순

`docs/POSTMORTEM.md` 의 첫 번째 규칙이 「화면 면적 순으로 일한다」입니다.
아래 순서가 그 순서입니다.

## ① 배 안의 무늬 (화면의 98%) — 512 x 512, 이어 붙는 것

| 파일 | 무엇 | 지금 대신 쓰는 색 |
|---|---|---|
| `surf/hull_wall` | 선체 벽 — 금속판·리벳 | `#4a4f57` |
| `surf/hull_floor` | 바닥 — 격자 발판 | `#35383d` |
| `surf/hull_ceil` | 천장 — 배관이 지나간다 | `#2a2d31` |
| `surf/engine_wall` | 기관실 벽 — 거칠고 그을렸다 | `#4b423c` |

**왼쪽 끝과 오른쪽 끝이 만나도 티가 안 나야 합니다** (seamless / tileable).
벽 한 장이 월드 4 x 2.6 유닛을 덮습니다.

### 곁그림 — 있으면 훨씬 좋아집니다 (없어도 됩니다)

받으시는 무늬가 대개 세 장 묶음으로 옵니다. 꼬리표만 붙여 같이 넣으면
게임이 알아서 씁니다.

| 꼬리표 | 무엇 | 흔한 원본 이름 |
|---|---|---|
| `_n` | 굴곡 (보라빛 그림) | `*_NormalGL` |
| `_r` | 거칠기 (흑백) | `*_Roughness` |

예: `surf/hull_wall.png` · `surf/hull_wall_n.png` · `surf/hull_wall_r.png`

> **노멀은 GL 쪽을 받으십시오.** `NormalDX` 는 초록 채널이 뒤집혀 있어서
> 빛이 반대로 팹니다 — 화면상으로는 「어딘가 어색함」으로만 보이고
> 원인이 안 보입니다.

## ② 창밖 (조종석에선 화면의 절반)

| 파일 | 크기 | 무엇 |
|---|---|---|
| `sky/deep` | 4096 x 2048 | 깊은 우주 — 별과 성운. **가로:세로 2:1 파노라마** |
| `sky/planet` | 2048 x 2048 | 행성 한 장 (알파 배경) |

## ③ 나머지

| 파일 | 크기 | 무엇 |
|---|---|---|
| `decal/panel` | 1024 x 1024 | 계기·눈금·라벨·경고 표지 모음판 |
| `fx/dot` | 64 x 64 | 먼지·불티·빛무리 |
| `fx/steam` | 128 x 128 | 새어 나오는 김 |
| `fx/glow` | 128 x 128 | 등의 번짐 |

`fx/` 는 **흰색/회색 + 알파로만** 그립니다. 게임이 색을 곱해 씁니다 —
그림에 색이 있으면 붉은 경고등도 푸른 냉기도 그 색에 물듭니다.
