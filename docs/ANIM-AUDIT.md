완전히 없애려면 대검을 거의 수평으로 휘두르게 해야 하는데, 그건 「내려베기」를
버리는 것이라 여기서 멈췄다.

## 0. 결론 먼저

어색함의 원인은 셋이고, **가장 큰 것은 애니메이션이 아니라 무기 자체**입니다.

| # | 무엇 | 왜 어색한가 | 비용 |
|---|---|---|---|
| **1** | **장착한 무기가 화면에 안 나타난다** | 12종 무기가 전부 **같은 검 하나**로 보인다 | 중 |
| **2** | 손이 손잡이를 안 쥐고 **밑동에 붙어 있다** | 두 손 무기도 한 손, 폼멜이 손목을 뚫는다 | 소 |
| **3** | 동작에 **겹침(overlap)과 여운(follow-through)이 없다** | 몸의 모든 부위가 같은 순간에 멈춘다 | 소~중 |

## 1. 장착한 무기가 화면에 안 나타난다 — **제일 큰 문제**

`items.js` 에는 무기 계열이 여섯, 기반 무기가 열여덟 개 있습니다.

```
검(4) · 도끼(3) · 둔기(3) · 대검(3) · 단검(3) · 지팡이(2)
녹슨 검 … 처형자(대검 dmg 14–20 spd 0.64) … 독니(단검 spd 1.58)
```

그런데 `core/models.js` 의 `buildKnight()` 는 **검 하나를 고정으로 만들고 끝**입니다.
장착이 바뀔 때 도는 코드는 이것뿐입니다:

```js
_syncBlade() {                       // game/player.js:159
  const w = this.equipped.weapon;
  this.rig.bladeMat.color.set(r.hex);   // ← 색만 바꾼다
}
```

**즉 처형자(대검)를 껴도 화면에는 여전히 짧은 한손검이 보입니다.** 색만 등급에
따라 바뀝니다. 무기를 바꿔 끼는 것이 이 게임의 핵심 보상인데, 그 보상이
**화면에 하나도 반영되지 않습니다.**

동작 쪽에도 같은 문제가 번집니다. `STANCE.knight` 는 `windup: 2.15 · weight: 1.0`
하나뿐이라 **단검을 껴도 대검처럼 크게 휘두릅니다.** 공격 속도(`aspd` 0.64~1.58,
2.5배 차이)만 빨라지므로, 빠른 무기일수록 **큰 동작이 잘려 보입니다** — 이게
「모션이 어색하다」의 상당 부분입니다.

### 조치안

1. **계열별 무기 메시 6종** (`buildWeapon(fam)`). 지금 검을 만드는 코드가 8줄이니
   계열 하나에 ~10줄입니다. `rig.handR` 에 붙이고 장착 시 교체합니다
2. **계열별 STANCE 덮어쓰기** — 표 하나로 끝납니다
   ```js
   const WEAPON_STANCE = {
     단검:   { windup: 1.5, follow: 0.7, weight: 0.5, across: 0.5 },  // 짧고 빠르게 찌른다
     대검:   { windup: 2.4, follow: 1.15, weight: 1.5, out: 0.75 },   // 크게 돌려 벤다
     둔기:   { windup: 2.3, follow: 1.05, weight: 1.6 },              // 위에서 아래로 내리찍는다
     도끼:   { windup: 2.25, follow: 1.0, weight: 1.3 },
     지팡이: { windup: 1.8, follow: 0.8, weight: 0.7 },
   };
   ```
3. **두 손 무기는 왼손을 손잡이에 붙인다** — 대검·둔기일 때 `armL` 목표를
   오른손 위치로 잡습니다. 이것 하나로 무게가 크게 살아납니다

## 2. 손이 손잡이를 안 쥔다

```js
const weapon = new THREE.Group();
weapon.position.set(0, -0.06, 0.04);     // core/models.js:136
weapon.rotation.x = Math.PI - 0.28;
wp.add(prism(...), leather, { y: 0.06 });        // 손잡이
wp.add(prism(...), gold,    { y: -0.16 });       // 폼멜
```

무기 그룹의 원점이 손 위치이고, 손잡이가 `y: 0.06`, 폼멜이 `y: -0.16` 입니다.
즉 **주먹의 중심이 손잡이 중간이 아니라 그 아래**에 있고, 폼멜이 손 안쪽으로
0.16 들어가 있습니다. 손이 무기를 **쥔 게 아니라 무기가 손에 꽂혀 있습니다.**

칼끝 방향은 이미 한 번 고쳐서 맞습니다 (`weaponHeldForward` 검사가 지킵니다 —
기사 0.53 · 해골 0.417, 음수면 거꾸로 쥔 것). 남은 것은 **쥐는 위치**입니다.

### 조치안

- 무기 원점을 **손잡이 중앙**으로 옮긴다 (`y` 오프셋을 손잡이 길이의 절반으로)
- 손가락 대용으로 **손 위에 얇은 띠 하나**를 무기와 같은 각도로 붙인다.
  관절을 늘리지 않고 「쥐었다」가 읽히는 제일 싼 방법입니다

## 3. 겹침과 여운이 없다

게임 애니메이션 12원칙에서 지금 코드가 지키는 것과 빠뜨린 것입니다.

| 원칙 | 지금 | |
|---|---|---|
| 예비 동작 (Anticipation) | ✅ `k < 0.30` 구간에서 크게 든다 | 잘 되어 있다 |
| 완급 (Slow in/out) | ✅ `e = u*u` · `1-(1-u)³` 로 가감속 | 잘 되어 있다 |
| 호 (Arc) | ✅ 오른쪽 위 → 왼쪽 아래 대각선 | 잘 되어 있다 |
| 늦게 따라오기 (Overlap) | △ 골반·머리만 `chestY * 0.35 / 0.4` 로 지연 | **팔·무기에는 없다** |
| 여운 (Follow-through) | ❌ `k > 0.60` 에서 **바로 대기 자세로 되돌린다** | 없다 |
| 2차 동작 (Secondary) | ❌ 망토·검집·사슬이 안 흔들린다 | 없다 |

**여운이 없는 것이 핵심입니다.** 지금은 타격 직후 `armX` 가 `st.follow` 에서
곧장 `st.restR` 로 보간됩니다 — 검이 최저점을 **찍고 곧바로 되돌아옵니다.**
실제로는 관성 때문에 최저점을 **지나쳐서** 잠깐 멈췄다가 되돌아옵니다.

조사한 원칙 문서가 같은 것을 지적합니다:

> 관성은 즉시 멈추지 않으며, 이것이 물리적 무게를 알리는 **주요 신호 중 하나**다.
> 검은 타격 지점을 **지나쳐 계속 휘둘러진** 뒤에야 멈춘다.

그리고 이것도 지금 코드에 그대로 해당합니다:

> 주니어 애니메이터가 가장 흔히 하는 실수는 캐릭터의 **모든 요소가 같은 순간에
> 시작하고 같은 순간에 도착**하게 하는 것이다.

`poseAttack` 은 `armR.x`·`armR.z`·`foreR.x`·`chest`·`hips` 를 **전부 같은 `k`
구간에서 같은 보간 곡선**으로 움직입니다. 골반·머리만 배수로 줄여 놨을 뿐
**타이밍은 전부 동일**합니다.

### 조치안 (전부 `core/anim.js` 한 파일)

1. **여운 구간을 나눈다** — `k 0.60~0.72` 에서 `follow` 를 **12% 더 지나친 뒤**
   `0.72~1.0` 에서 대기로 돌아온다. 다섯 줄이면 됩니다
2. **관절마다 도착 시점을 어긋나게 한다** — 지금은 rate 가 `r`·`r*0.8`·`r*0.6`
   으로만 갈립니다. 어깨는 먼저, 팔꿈치는 0.03초 뒤, 손목은 0.05초 뒤에
   도착하게 **위상을 밀면** 채찍처럼 이어집니다
3. **피격에도 여운을 준다** — 지금 `poseHit` 은 젖혔다가 바로 돌아옵니다.
   맞은 방향으로 젖혔다가 **반대로 살짝 넘어갔다가** 돌아오면 충격이 읽힙니다
   (`springOut` 이 이미 있으니 피격 자세에도 태우면 됩니다)
4. **2차 동작 하나만** — 기사 망토나 해골 갈비뼈가 몸통 각속도를 0.08초 늦게
   따라오게. 관절 하나 추가로 「살아 있는 몸」이 크게 삽니다

## 4. 하는 순서

| 단계 | 하는 일 | 확인 | 상태 |
|---|---|---|---|
| **A** | 여운 + 관절 위상차 (`anim.js` 만) | 공격 8컷 캡처 비교 · `actor.*` 검사 유지 | ✅ |
| **B** | 무기 쥐는 위치 + 손 띠 | `weaponHeldForward` 유지 · 폼멜이 손목을 안 뚫는다 | ✅ |
| **C** | 계열별 무기 메시 6종 + 장착 시 교체 | 대검과 단검이 화면에서 다르다 | ✅ |
| **D** | 계열별 STANCE + 두 손 잡기 | 단검이 대검처럼 안 휘두른다 | ✅ |
| **E** | 2차 동작 (망토·갈비뼈) | 프레임 예산 확인 (`perf.simBudget`) | ❌ |

**E 를 안 한 이유**는 망토가 지금 가슴 관절의 `Part` 안에 **합쳐져 있어서**다.
따로 흔들려면 관절을 하나 더 파고 메시를 갈라야 하는데, 그건 A~D 와 달리
값 조정이 아니라 몸을 다시 만드는 일이다. A~D 로 무게가 읽히기 시작했으니
효과 대비 비용을 다시 재고 정하는 게 맞다.

## 5. 이 문서가 정하지 않은 것

- **정확한 수치.** 위 배율은 출발점입니다. 8컷 캡처로 보고 고쳐야 합니다
- **적의 무기 교체.** 적은 장비 시스템이 없으므로 계열 메시가 필요 없습니다.
  다만 변종(해골 창병 등)은 무기가 달라야 하므로 §1의 `buildWeapon` 을 씁니다
- **모션 캡처·외부 애니메이션.** 지금은 전부 절차적입니다. 리그가 `core/rig.js`
  로 표준화돼 있어 나중에 glTF 클립으로 갈아탈 수 있습니다 (`docs/ACTORS.md`)
