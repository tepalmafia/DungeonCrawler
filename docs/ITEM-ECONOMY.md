# 아이템·경제 기획안 — 적게 주되, 줄 때는 의미 있게

> 대상: `web/3d` (심연의 왕관)
> 상태: **기획. 미구현.** §8 의 컴펌을 받고 §7 순서대로 넣는다.
> 검증: 모든 수치는 `tools/bench3d.js` 로 재고 판정한다. 감으로 정하지 않는다.

---

## 0. 한 줄 진단

지금 드랍은 **양은 적지만 의미도 없다.** 잡몹 17% 확률로 아무거나 하나 떨어지고,
그게 좋은지 나쁜지는 툴팁을 열어야 안다. 그래서 줍는 행위에 감정이 없다.

사장님 지시는 두 개인데 서로 방향이 반대로 보입니다:

> ① 아이템 **가짓수**를 늘려라  ② 아이템이 **너무 많이 나오면** 재미가 없다

반대가 아닙니다. **가짓수는 늘리고 드랍 빈도는 줄이는 것**이 정답이고,
이 문서 전체가 그 한 문장의 각론입니다.

## 2. 설계 원칙 다섯

### 2-1. 「빈손으로 나가는 판」이 있어야 한다

매 판 뭔가 얻으면 얻는 게 기본값이 되고, 그러면 아무 감정도 안 생긴다.
**층 하나를 돌아도 장비가 안 바뀌는 경우**가 정상이어야 한다.
대신 그때는 **돈**이 남는다 (§4).

### 2-2. 떨어지는 것은 「내가 쓸 수 있는 것」에 치우친다

가짓수를 늘리면 무작위 드랍은 쓸모없는 것으로 채워진다. 그래서 **가중치**를 건다:

- 60% — 현재 착용 중인 슬롯과 **같은 슬롯**
- 40% — 아무 슬롯

내 무기보다 나쁜 무기가 계속 떨어지면 가짓수가 늘어난 게 아니라 소음이 늘어난 것이다.

### 2-3. 등급은 **바닥에서** 읽혀야 한다

이미 구현했다 — 등급별로 빛기둥 크기·바닥 고리·전설 불티가 다르다.
가짓수가 늘어도 **줍기 전에 판단**할 수 있어야 걸음이 아깝지 않다.

### 2-4. 돈은 「지금 못 쓰는 아이템」의 출구다

안 쓰는 장비를 팔아 돈이 되고, 그 돈으로 **원하는 것**을 산다.
무작위 드랍만 있으면 원하는 부위가 안 나올 때 방법이 없다. 상점이 그 보정이다.

### 2-5. 잃을 게 있어야 조심한다

사망 페널티(§6)가 있어야 §2-1 의 「빈손」이 아깝고, 랜턴 연료가 긴장되고,
「한 마리씩 신중하게」가 성립한다. **페널티는 이 게임 설계의 마지막 조각이다.**

## 3. 아이템 확장

### 3-1. 슬롯을 2 → 5 로

| 슬롯 | 성격 | 주 접사 |
|---|---|---|
| 무기 | 공격력의 축 | dmg, aspd, crit, leech |
| 투구 | 생존 | hp, armor, mp |
| 갑옷 | 생존의 축 | armor, hp |
| 장갑 | 공격 보조 | aspd, crit, cdmg |
| 장신구 | 변수 | cdr, speed, leech, mp |

슬롯이 늘면 **드랍 하나가 덜 중요해진다** — 5개 중 하나만 바뀌므로.
그게 §2-1 의 「안 바뀌는 판」을 자연스럽게 만든다.

### 3-2. 무기 5 → 12

| 계열 | 종류 | 성격 |
|---|---|---|
| 검 | 녹슨 검 · 장검 · 룬검 | 균형 |
| 도끼 | 강철 도끼 · 쌍날 도끼 | 느리고 세다 |
| 둔기 | 사슬 철퇴 · 성전 망치 | 제일 느리고 제일 세다 |
| 대검 | 흑요석 대검 · 처형자 | 느림 + 범위 |
| 단검 | 단검 · 독니 | 빠름 + 크리 |
| 지팡이 | 재의 지팡이 | 마나·쿨감 특화 |

**계열마다 속도·피해 곡선이 다르다.** 단순히 숫자만 큰 상위 호환을 만들지 않는다 —
그러면 12종이 아니라 1종을 12단계로 나눈 것에 불과하다.

### 3-3. 접사 10 → 16

추가: `thorns`(반사), `fuel`(랜턴 연료 최대치), `find`(드랍 등급 확률),
`stun`(기절 확률), `range`(공격 사거리), `regen`(체력 재생).

`fuel` 과 `find` 는 **이 게임에만 있는 접사**다. 랜턴 시스템과 드랍 억제라는
이 게임의 두 축에 직접 붙는다.

### 3-4. 세트 — **넣지 않는다**

지금 규모에서 세트를 넣으면 「세트 완성 전까지 전부 쓰레기」가 된다.
가짓수를 늘리는 목적과 반대다. 나중에 콘텐츠가 3배가 되면 재검토한다.

## 4. 화폐와 상점

### 4-1. 화폐 — 「영혼 조각」

- 잡몹 처치 시 **확정 드랍** (자동 획득, 줍는 동작 없음)
- 층·티어에 비례: `3 + floor*2 + tier*3` (± 30%)
- 정예 ×6, 보스 ×25

**확정 드랍**인 이유: 아이템이 안 나와도 판이 헛되지 않아야 한다(§2-1).

### 4-2. 상점 — 던전 안, 함정 방에

사장님 지시대로 **던전 안에** 둔다. 안전지대가 아니다.

| 항목 | 설계 |
|---|---|
| 위치 | 층마다 1개. 시작 방·보스 방이 아닌 방 하나 |
| 진입 | 방 입구에 **함정이 깔려 있다** (`docs/DUNGEON-INTERACTIONS.md` §3) |
| 상인 | 「재의 행상」 — 중립. 공격당하지 않고 공격하지 않는다 |
| 재고 | 6칸. 층 진입 시 굴린다. **떠나면 다시 안 산다** |
| 판매 | 가방의 아이템을 판다. 가격 = 아이템 등급·접사 기준 |
| 구매 | 재고에서 산다. 가격 = 판매가 × 3.5 |

**왜 함정 방인가**: 상점이 공짜 편의 시설이 되면 「돈이 있으면 무조건 이득」이
된다. 함정을 뚫고 들어가야 하면 **갈지 말지가 판단거리**가 된다. 랜턴 연료가
간당간당할 때 상점을 들를지 말지 — 그 갈등이 이 게임의 감정이다.

### 4-3. 재고 구성 (6칸)

```
1칸  소모품 (물약)              항상
1칸  랜턴 또는 연료             항상    ← 랜턴 시스템의 안전판
3칸  장비 (내 레벨 ±2, 무작위 슬롯)
1칸  「오늘의 물건」 — 희귀 이상 확정. 비싸다
```

「오늘의 물건」이 있어야 **돈을 모을 이유**가 생긴다. 전부 싼 물건이면
돈이 남아돌고 화폐가 의미를 잃는다.

## 5. 드랍 억제 — 수치

| 대상 | 현재 | 변경안 |
|---|---:|---:|
| 잡몹 장비 드랍 | 17% + 티어 2% | **9%** + 티어 1.5% |
| 잡몹 영혼 조각 | 없음 | **100%** |
| 정예 장비 | 확정 1 + 50% 추가 | 확정 1 (추가 없음) |
| 보스 장비 | 확정 3 | 확정 **2** + 「오늘의 물건」 할인권 |
| 등급 분포 | — | 일반 55 / 고급 30 / 희귀 12 / 전설 3 |

**목표 수치** (실측으로 판정):

```
층 하나(약 90초)당 장비 획득     2~3개      ← 지금은 측정 필요
그중 실제로 갈아입는 것          0~1개
층 하나당 영혼 조각              80~140
상점에서 장비 하나 값            약 350     ← 3~4층 모아야 하나 산다
```

**「3~4층 모아야 하나 산다」**가 이 경제의 심장이다. 매 층 살 수 있으면
상점이 자판기가 되고, 10층 모아야 하면 존재감이 없어진다.

## 6. 사망 페널티

사장님 지시: **사망 시 착용 아이템을 무작위로 잃을 수 있다.**

### 6-1. 규칙안

```
사망 시:
  · 착용 중인 5칸 중 무작위로 1칸을 고른다
  · 그 칸이 비어 있으면 → 아무 일도 없다 (초반 보호가 저절로 된다)
  · 차 있으면 → 등급에 따라 잃을 확률
        일반 60% · 고급 45% · 희귀 30% · 전설 15%
  · 잃은 아이템은 **죽은 자리에 떨어진다** (사라지지 않는다)
  · 영혼 조각은 30% 잃는다
```

### 6-2. 왜 「떨어진다」인가

완전 소멸은 벌이 너무 무겁고, 무사히 부활은 벌이 아니다.
**죽은 자리로 되찾으러 가는 것**이 정답이다 — 디아블로2 의 시체 회수와 같은 구조고,
이 게임에는 특히 잘 맞습니다. **랜턴 연료를 써 가며 어두운 길을 되돌아가야** 하니까요.

- 떨어진 장비는 그 층에 **영구히** 남는다 (층을 넘기면 사라진다)
- 되찾으러 가는 길에 적은 **부활해 있지 않다** — 벌을 두 번 주지 않는다

### 6-3. 전설 15%인 이유

전설을 자주 잃게 하면 좋은 물건을 **안 입게 된다.** 아껴 두고 낡은 걸 입는 건
설계 실패다. 등급이 높을수록 덜 잃어야 「입어도 되겠다」가 된다.

## 7. 구현 순서

| 단계 | 내용 | 검증 |
|---|---|---|
| **1** | 슬롯 2→5, 무기 5→12, 접사 16종 | 각 슬롯이 실제로 채워지는가 · 계열별 속도 곡선이 다른가 |
| **2** | 드랍 억제 + 슬롯 가중치 (§2-2, §5) | **층당 획득 2~3개**가 실측으로 나오는가 |
| **3** | 영혼 조각 + HUD 표시 | 층당 80~140 이 나오는가 |
| **4** | 상점 (함정 방 배치는 함정 구현 뒤) | 장비 하나 값 = 3~4층치인가 |
| **5** | 사망 페널티 + 시체 회수 | 되찾기가 실제로 가능한가 · 초반 5분 사망이 게임을 끝내지 않는가 |
| **6** | 인벤토리 UI 개편 (별도 작업) | — |

**단계 2 와 3 사이에 반드시 벤치를 돌린다.** 드랍을 줄이면 성장이 느려지고,
성장이 느려지면 처치 시간이 늘고, 그러면 층당 시간이 늘어난다. 연쇄가 있다.

### 7-1. 실측에 추가할 지표

```
itemsPerFloor      층당 획득 장비 수
upgradesPerFloor   실제로 갈아입은 횟수      ← 이게 진짜 지표다
coinPerFloor       층당 영혼 조각
coinBalance        보유 잔액 시계열
shopVisits         상점 방문 / 구매 횟수
deathLosses        사망당 잃은 아이템 수 · 회수 성공률
```

`upgradesPerFloor` 가 핵심이다. 아이템을 20개 주워도 하나도 안 갈아입으면
드랍은 **소음**이다. 목표는 층당 **0.7~1.2**.

## 8. 컴펌 받을 것

1. **§5 드랍률 17% → 9%.** 절반 아래로 내립니다. 「너무 많이 나오면 재미없다」는
   지시를 이렇게 해석했는데, 더 내릴지 덜 내릴지 판단이 필요합니다.

2. **§6-2 시체 회수.** 잃은 장비를 죽은 자리에서 되찾는 방식입니다.
   완전 소멸을 원하시면 벌이 훨씬 무거워집니다 — 어느 쪽입니까?

3. **§4-2 상점이 층마다 1개.** 층당 1개면 자주 만나고, 3층에 1개면 귀합니다.

4. **§3-4 세트 아이템 제외.** 지금 규모에서는 넣지 않는 게 맞다고 봅니다.

5. **§4-1 영혼 조각이 100% 확정 드랍.** 「빈손으로 나가는 판」을 없애는 장치인데,
   확정 보상이 있으면 긴장이 줄기도 합니다.

## 9. 이 문서가 다루지 않은 것

- **인벤토리 UI**: 사장님이 주신 디아블로 스크린샷 기준으로 별도 작업.
  격자 인벤토리로 갈지 목록형을 유지할지는 이 문서의 대상이 아니다.
- **상인 대사**: 스토리 기획(`docs/STORY.md`, 미작성) 뒤.
- **아이템 아이콘**: 지금은 이모지를 쓴다. 가짓수가 12+가 되면 이모지로는
  구분이 안 될 수 있다 — 실제로 늘려 보고 판단한다.
- **밸런스 최종 수치**: 여기 적은 숫자는 **출발점**이다. 단계마다 벤치를 돌려
  고친다. 이 문서의 숫자를 「정답」으로 읽지 말 것.
