## 0. 한 문장 — 보스전 40초 동안 무엇이 일어나는가

> **0~3초** 보스가 자기 죄목을 말하며 걸어 들어온다(이때부터 때릴 수 있다). **3~12초** 페이즈1, 서로 다른 초식 4개가 겹치지 않고 돌아간다. **12~16초** 보스가 큰 것을 시전한다 — 머리 위에 게이지가 차고, **이 동안 보스는 경직되지 않지만 받는 피해는 1.5배다.** 때려서 끊을지 물러나 피할지 내가 고른다. **16~17초** 끊으면 보스가 자기 함정에 빠져 2초 무방비. **17~18초** 체력 절반, 전환 컷 0.8초 + 아레나에 영구 변화 1줄(불줄·구덩이·철창)이 남아 방이 실제로 좁아진다. **18~34초** 페이즈2, 신규 초식 2개 해금 + 이제 인장기가 온다. **34~40초** 25% 이하 맹공 — 간격 0.6배, 발밑 추적 장판. 그리고 죽으며 유언 한 줄.

**한 판에 서로 다른 그림 6개 이상, 보스가 무방비가 되는 순간 2회 이상, 내가 만든 무방비 1회 이상.** 이게 목표다.

### 1-3. HP를 올리는 안이 왜 금지인가 — 실측 근거

v192에서 오스문드 HP를 올렸다. 사장은 여전히 13초에 잡았다. 그리고 시간을 늘려도 목격 패턴은 안 는다:

| 컷 | 5초 | 10초 | **13초** | 15초 | 20초 | 30초 |
|---|---|---|---|---|---|---|
| 1층 목격 동사 | 1.3 | 3.7 | **4.0** | 4.3 | 4.3 | 4.3 |
| 5층 목격 동사 | 3.7 | 4.3 | **4.3** | 4.3 | 4.3 | 5.0 |

[실측] **시간을 2.3배(13→30초) 줘도 목격 패턴은 +0.3개다.** HP를 두 배로 올리면 같은 그림을 18번 보게 될 뿐이다. 그게 「지루하다」의 정의다.

→ **그래서 목표 지표를 TTK에서 「13초 안에 목격하는 서로 다른 그림 수」로 바꾼다.** 목표: **4.0 → 6.0개.** TTK는 그 다음이다.

## 3. 무적·페이즈 설계 — 사장 질문에 대한 답

### 3-1. 답: **부분 채택. 층 구간별로 다르게 간다.**

사장이 말한 「스킬 쓸 때 무적」은 **이미 우리 코드에 있다**(veil). 문제는 4종만 쓰고, 사장이 실제로 만나는 1~4층엔 하나도 없다는 것.

그런데 **1층에 그대로 넣으면 안 된다.** 계산:

> 1층 TTK 13초. 여기에 5초 무적을 넣으면 **전투의 38%가 무적**이다. 현행 veil 상한 8초를 그대로 쓰면 **62%**다.
> 이건 Hollow Knight 우무(Uumuu)와 정확히 같은 상황이다 — "전투의 90%를 기다린다", "어렵지 않고 지루하다. 때릴 기회를 기다리는 게 진짜 문제". (※ Steam 커뮤니티 게시물 요약 기반, 개발자 진술 아님)

**그래서 층 구간별로 다른 장치를 쓴다:**

### 3-2. 무적 3원칙 — 이걸 어기는 무적은 넣지 않는다

1. **무적은 반드시 플레이어 행동으로 끝난다.** 시간으로만 끝나는 무적은 금지. 상한 타이머는 안전장치일 뿐 정상 종료 수단이 아니다.
2. **해제 조건 오브젝트는 결정론적 위치 + 즉시 타격 가능.** (우리 soulOrb는 `speed=0`, `spawnT=0`으로 **이미 옳다** [실측]. 우무-오마의 실패 원인이 랜덤 소환 타이밍과 보스와의 겹침이었다.)
3. **무적 중에도 플레이어 입력이 버려지지 않는다** → **P7 딜 저금** 필수. 원거리·고딜 빌드의 박탈감을 제거하는 유일한 장치이고 비용은 S다.

## 4. 화면 예산 — 동시 표시 요소 상한

고정 화면 한 장에 v188 예고(붉은 부채꼴 2개 + 백열 고리) + v185 무리 표시 + 소환수 + 유성우 예고 5개가 겹치면 읽을 수 없다. **수치로 상한을 박는다.**

### 4-1. 면적 계산 (864×432 = 373,248 px² 기준)

| 패턴 | 예고 마커 총면적 | 아레나 대비 |
|---|---|---|
| mortar 5발 (r=46) | 5 × π×46² = 33,238 px² | **8.9%** |
| curse 4발 (r=48) | 4 × π×48² = 28,953 px² | **7.8%** |
| geyser 4발 (r=48) | 28,953 px² | **7.8%** |
| snare 3발 (r=55) | 3 × π×55² = 28,510 px² | **7.6%** |
| sweep 부채꼴 2개 (r=108, ±1.35rad) | 2 × ½×2.7×108² = 31,492 px² | **8.4%** |
| ring 판정 띠 (r=340, 폭 30) | 2π×340×30 = 64,088 px² | **17.2%** |
| charge 직선 (520×48) | 24,960 px² | **6.7%** |

### 4-2. 상한 — 하드 룰

| 계층 | **상한** | 근거 |
|---|---|---|
| **붉은 예고 마커 개수** | **동시 6개** | mortar 5 + 접촉 예고 1 = 6이 최대 조합 |
| **붉은 예고 마커 총면적** | **아레나의 25% (93,300 px²)** | 8% 짜리 3종이 겹치는 순간이 상한. 4종 겹치면 33% — 갈 곳이 없다 |
| **지속 판정체** (투사체+링 겹+장판) | **동시 18개** | fan:gap 13발 + ring 2겹 + 장판 3 = 18 |
| **살아있는 엔티티** (보스 제외) | **4개** (부하 3 상한 + 구슬은 부하와 **합산**) | 장막 중에는 구슬 3 → 부하 소환 금지 |
| **텍스트 배너** | **동시 1개 · 최소 표시 0.7초 · 최소 간격 1.2초** | 「일어나라!」 + 죄목 낭독 + 전환 배너가 겹치는 것을 막는다 |
| **보스 HP바 아래 게이지** | **동시 1줄만** — 장갑 / 붕괴 / 시전 중 하나. **2개 동시 표시 절대 금지** | 3-1의 층 구간별 차등이 이 제약에서 나온 것이기도 하다 |
| **무리 표시(v185)** | 보스전 중에는 **보스 자신에게만 표시**, 부하는 표시 생략 | 부하 3마리에 각각 링을 그리면 예산 초과 |

### 4-3. 큐잉 규칙 — 초과를 막는 실행 규칙

> **예고 마커 총면적이 25%를 넘게 되는 패턴은 발동을 0.3초 지연하고, 지연이 2회 누적되면 그 패턴을 건너뛴다.**
> 이 규칙 하나로 "우연히 3개가 겹쳐 회피 불가"가 구조적으로 사라진다. 랜덤 조합을 사람이 전수 검증할 수 없으므로, 검증 대신 **런타임 상한**을 둔다.

### 5-2. 1~5층 상세 — 사장이 실제로 도달하는 구간

여기가 스팀 ₩10,000의 구매 판단 구간이다. **현재 이 구간에서 게임의 화려한 도구가 절반 잠겨 있다:** 14개 동사 중 spiral·snare·geyser·beam·echo 5개 미등장, 인장기 7종 전부 미등장, 3페이즈 맹공 미등장 [실측].

#### 【1층】 무덤지기 오스문드 — "나는 파기만 했다. 넣으라 한 건 위였어."

**현 상태 [실측]:** 23종 중 **유일하게 기믹도 인장기도 3페이즈도 없다.** 가진 것은 실HP 118과 페이즈2 전환 하나뿐. 3회 중 2회가 페이즈1을 「휘두르기 4연속」으로 보냈다. **사장이 「너무 쉽게 잡더라」라고 한 그 판이다.**

**진단:** HP가 낮아서가 아니다. **장치가 0개이고, 481행 버그가 p1을 sweep 1개로 붕괴시켰다.**

**설계 — 첫 기믹은 「판다」다.**

> 죄목이 「묻은 손」이다. 그는 판다. 그러니 그의 대형기는 **무덤 흙을 퍼올리는 것**이고, 그를 이기는 법은 **그가 판 구덩이에 그를 빠뜨리는 것**이다.

| 항목 | 값 |
|---|---|
| **정체성 기믹** | **파묘(破墓) 인터럽트** (P1) |
| 발동 | 전투 시작 후 첫 시전 8초 시점 + 이후 12초마다. 페이즈2에서는 9초마다 |
| **시전 게이지** | **2200ms** — 머리 위 흙색 게이지. 「무덤을 판다」 텍스트 |
| 시전 중 보스 상태 | **무적 아님.** 무경직 + **받는 피해 ×1.5** + 이동 정지 |
| 취소 임계 | 최대HP의 **12%** 누적 피해 (실HP 140 기준 **17 피해**) — 사장 화력(buildAtk 4)이면 약 1.2초 |
| **성공 시** | 시전 취소 + 「제가 판 구덩이에 빠졌다」 + **그로기 2.0초** (확정 딜타임, 피해 ×1.5 유지) |
| **실패 시** | 유성우 5발(mortar, 마커 2단계 P16, 예고 720~1350ms) + 착탄 지점에 구덩이 3개(감속 1.6초, 2.5초 잔류) |
| **1층에 무적을 넣지 않는 이유** | TTK 20초에 4초 무적 = 전투의 20%. 첫 보스에서 「때릴 수 없는 시간」을 가르치면 사장이 산 그 20분이 기다림으로 시작한다. **첫 보스는 「보스가 특별해지는 순간 = 내가 개입할 순간」을 가르치는 자리다.** |

**패턴 구성**

- **p1 (5개, 481행 수정 전제):** `sweep>sweep` / `fan:rock` / `mortar` / `summon:skeleton` / **`cast:파묘`**
- **p2 (6개):** 위 전부 + `ring`(흙먼지 고리) + `curse`
- **p3:** 없음 (`awakened` 없음 유지 — 1층에 3단계는 과하다)
- **소환 상한:** 동시 3, 재소환 총 **2회** (P12). 「일어나라!」
- **무기:** 흙·뼈. fan은 뼛조각(bone, 크림색), ring은 흙먼지 고리 — 흰 원이 아니다
- **인장기:** 없음 유지. 대신 파묘 시전 시 **죄목 낭독**(P15): 「…나는 파기만 했다」

**수치 목표**

| 지표 | 현재 [실측] | **목표** |
|---|---|---|
| 실HP | 118 | **140** (`def.hp` 190→226, ×0.62) |
| TTK | 13~14초 | **20초** ±3 |
| **13초 컷 목격 서로 다른 동사** | **4.0** (p1은 1.33) | **6.0 이상** (p1 4개 이상) |
| 최빈 패턴 점유율 | sweep 56~67% | **35% 이하** |
| 보스 무방비 구간 | 0초 (charge 없음) | **2.0초 × 1~2회** (전부 플레이어가 만든다) |

> **HP는 +19%만 올린다.** TTK 13→20초 중 늘어난 7초의 출처: HP +19%가 약 2.5초, 등장 무적 1.0초, 전환 컷 0.8초, 유성우 회피로 인한 접근 지연 약 2.5초. **인터럽트 자체는 TTK를 오히려 1~2초 줄인다(피해 ×1.5 창).** 이건 의도한 것이다 — 사장이 원한 건 긴 전투가 아니라 **밀도**다.

#### 【2층】 삯꾼 몰레 — "삯이었다… 그저 삯이었단 말이다…"

**현 상태 [실측]:** `regen` 기믹. 실HP 105. 봇 TTK 33초(사장은 더 짧을 것).

**진단:** regen은 **부정적 피드백**이다 — 「보스 HP가 안 줄어든다」는 좌절만 준다. 플레이어의 행동을 바꾸지 않는다.

**설계 — 「나른다 / 값을 받는다」를 그대로 기믹으로.**

> 몰레는 수레를 끈다. 수레의 짐이 그의 삯이다. **짐이 있는 한 그는 지지 않는다.**

| 항목 | 값 |
|---|---|
| **정체성 기믹** | **삯의 연결** (P3 — regen의 정확한 상위 호환) |
| 동작 | 전투 시작 시 수레 짐 2마리(시체 부하) 등장. **살아있는 동안 보스 피해 -40%** |
| 단계 해제 | 1마리 죽을 때마다 -40% → -20% → 0% |
| **전멸 보상** | **3초 취약 (받는 피해 ×1.5)** + 「삯을 잃었다」 |
| 재소환 | 총 **2회**, 동시 상한 **3** (P12). 소환 예고 600ms |
| regen과의 차이 | regen은 "내 딜이 사라진다"(부정), 이건 "내 딜이 배가 된다"(긍정). **같은 서사, 반대 감정** |

- **p1:** `fan:spore` / `summon:corpse` / `snare` / `curse` / `uniq:짐부리기`
- **p2:** + `ring`(수레바퀴 고리) / `geyser:poison`
- **무기:** 포자(spore, 초록, 속도 135). ring은 수레바퀴 자국
- **목표:** TTK **24초**, 13초 컷 목격 **6개**, 부하 동시 최대 3

#### 【4층】 그을음 브란트 — "불은 명령이었다. 안에 사람이 있는 줄은… 알았다."

**현 상태 [실측]:** `rage`. 실HP 267. 봇 TTK 121초(전 층 최장). 여기서 이미 「같은 것을 20~40번 본다」가 발생한다.

|---|---|
| **정체성 기믹** | **자기 불에 갇힌다** (P10 아레나 영구 변화의 4층판) |
| 동작 | 대형기 시전마다 아레나 **가장자리부터 불줄이 한 줄** 남는다 (y폭 **96px** = 2타일) |
| 상한 | **최대 2줄.** 유효 세로 432 중 192px(44%)를 뺏는다. **3줄 금지** — 회피 불능 |
| 보스에게도 적용 | 보스도 불 위에서 이동속도 **-15%** — 「불이 나만은 알아볼 줄 알았는데」의 복선 |

#### 【5층】 교수대의 그림자 — "우리를… 세어라. 아무도 세지 않았다."

**현 상태 [실측]:** 유일하게 진짜 무적(`veil`)을 가진 1~5층 보스. 무적 창 2회, 각 2.94~6.86초, 전투당 총 7.69~10.10초 = **TTK의 6~9%**. 실HP 434, 봇 TTK 114초.

**설계 — 「센다 / 이름을 부른다」. 서사가 이미 기믹이다.**

| 항목 | 현행 | **개정** |
|---|---|---|
| 무적 상한 | 8.0초 | **4.0초** |

| **구슬 표시** | 보라 발광 구체 | **구체 위에 숫자 3 / 2 / 1.** 부술 때마다 카운트다운. 「아무도 세지 않았다」가 화면에서 진행된다 |
| 성공 | 그로기 1.4초 | 그로기 1.4초 + **딜 저금 방출** (P7) |
| 실패 | 최대HP **25%** 회복 + 9발 부채꼴 | 최대HP **12%** 회복 + 9발 부채꼴 |
| 조기 해제 | 없음 | **P6 반사** — 무적 진입 0.8초 뒤 큰 혼구슬 1발(속도 160, 예고 600ms). 완벽 회피 창(0.24초) 또는 근접 타격으로 되받아 명중 시 **즉시 해제 + 그로기 2.5초** |
| 무적 중 신규 위험체 | — | **금지** (구슬·반사탄 제외) |

**「기다리는 게임」이 안 되는 근거 (숫자):**
> 개정 후 무적 총량 = 4.0초 × 2회 = **최대 8.0초.** TTK 목표 32초 대비 **25%.** 그리고 그 8초는 구슬 3개 파괴 + 반사 1회라는 **명확한 과제**로 채워져 있고, 반사에 성공하면 실제 무적 시간은 회당 1.5~2.5초로 줄어든다 [추정]. 우무의 실패 조건(무적이 시간으로만 끝남 / 해제 오브젝트가 랜덤 / 보스와 겹쳐 유도 불가)에 **하나도 해당하지 않는다.**

- **p1:** `fan:soul` / `ring` / `echo` / `summon:wraith` / `uniq:합장`
- **p2:** + `pulse` / `beam` — **1~5층 최초의 beam.** 여기서 처음 "보스가 광선을 쏜다"를 보여준다
- **무기:** 밧줄·혼(soul, 보라). ring은 밧줄 고리
- **목표:** TTK **32초**, 13초 컷 목격 **6개**, 무적 총량 TTK의 **25% 이하**

## 6. 우두머리(정예) 설계 — 방마다 나오는 보스급

**현 상태 [실측]:** 기술이 **강타 1종뿐.** 예고 0.75초 → 링 `maxR 125, speed 250, width 12, dmg 1`, 쿨 2.0~3.2초. HP = `max(원본×3, (46+층×11)×층배율)`.
**코드 주석에 우리 자체 실측이 남아 있다: 사장 화력이면 1.5초에 죽어 강타를 1회만 본다.**

## 실행 기록 — 2단계 시전 인터럽트 완료 (v202)

사장: **"보스가 스킬쓸때 무적이 된다던가. 그런거 없어?"** → 승인 **"무적은 시전 인터럽트로"**

### 설계 요지 — 무적의 반대로 간다

무적으로 딜을 막으면 플레이어가 **할 일이 없어진다**. 그래서 반대로 만들었다:

> **시전 중 보스는 더 아프게 맞고(×1.5), 대신 경직되지 않는다(무경직).**
> → 「무적이라 못 때린다」가 아니라 **「지금 때려야 한다」**가 된다.

| 항목 | 값 |
|---|---|
| 시전 창 | 2.2초 (1~5층) / 1.6초 (6층+) |
| 차단 임계 | **최대 HP의 12%** — 층이 올라도 「몇 대」의 감각이 유지된다 |
| 시전 중 | 무경직(넉백 면역) + 받는 피해 **×1.5** |
| 끊었을 때 | **2.0초 그로기** — 이 동안 받는 피해 ×1.35 |
| 못 끊었을 때 | 고유기(uniq)가 **그대로 나간다** |

**넉백 면역이 핵심 조건이다.** 이게 없으면 화력 없이 밀어내기로 시전을 흐트러뜨리는 우회로가 생기고,
「끊으려면 화력이 필요하다」가 성립하지 않는다. 화력이 약한 빌드는 못 끊는다 — 그게 성장의 보상이 된다.

### 화면 표시

보스 머리 위 게이지 **2중**: 붉은 막대가 시전 진행(다 차면 큰 게 나온다), 그 아래 노란 막대가
**차단까지 얼마나 남았는지**. 끊으면 「시전 차단!」 + 슬로모 0.35초 + 화면 흔들림, 그로기 중엔
머리 위를 도는 별.
