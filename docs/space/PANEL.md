## 0. 좌우가 반대였다 — **재서 고쳤다**

v66 에서 창밖에 yaw 를 물리면서 「배가 오른쪽으로 틀면 창밖은 왼쪽으로
흐른다」고 **글로 추론하고** `-att.yaw` 를 넣었다. 사장님이 반대라고
하셨고, 창밖 그룹에 표시점을 박아 재 보니 맞았다:

```
밀기 전   x  0.000
오른쪽    x +0.223   ← 같이 오른쪽으로 갔다   (고치기 전)
오른쪽    x −0.238   ← 왼쪽으로 흐른다        (고친 뒤)
```

**세 축의 부호는 머리로 맞히는 것이 아니라 화면에 점을 박고 재는 것이다.**

## 1. 손 — **조작기를 좌석 팔걸이로**

지금 옆 콘솔이 좌석에서 1.45m 옆에 **큰 덩어리**로 서 있고, 사장님
스크린샷에서 그게 **전력 배분 계기를 가리고** 있다.

실제 전투기의 스로틀은 **좌석 팔걸이 바로 옆**이다 (팔을 얹은 채 손가락만
움직인다). 콘솔 덩어리를 없애고 **팔걸이**로 옮긴다:

| | v68 | v69 |
|---|---|---|
| 추력 레버 | x −1.45 · 큰 콘솔 | **x −0.62 팔걸이** |
| 자동 항법 | x +1.45 · 큰 콘솔 | **x +0.62 팔걸이** |

깊이는 좌석과 같게 둔다 (`z = DEP.z`) — 그래야 방위각이 **85도**라
계기판(47~62도)과 안 겹친다. v68 에서 이걸로 한 번 데었다.

## 2. 눈 — **앉으면 뜨는 상태창** (「퀘스트 안내창처럼」)

계기를 세 군데서 봐야 했다: 대시 화면 넷 · HUD · 손목. 그런데 대시는
고개를 숙여야 하고, 숙이면 창이 안 보인다 (v63 이 고친 그것).

→ **앉으면 화면 오른쪽에 반투명 목록**이 뜬다. 세로로 한 줄씩:

```
  열      ▓▓▓▓▓░░░  62      ← 넘으면 벽이 달아오른다
  냉각    켜짐            ← 「냉각이나 속도」
  속도    1.0×  성운
  전력    추진·냉각·탐지
  자국    33 / 52
  항로    구간 4 · 남은 8
  탄약    레이저 · 열추적 3 · 유도 1
```

★ **새 규칙을 안 만든다.** 전부 이미 있는 값이고, 대시 화면이 보여주던
  것을 **앉은 자세에서 고개를 안 숙이고** 보게 하는 것뿐이다.
★ 서면 사라진다 — 걸어다닐 때는 **손목**이 그 일을 한다.

## 3. **다른 모니터에서도** — 정비실 작업대

「운전석에 탔을때 외에도 다른 모니터에서 확인할 수 있도록」.
정비실 작업대(`world/bench.js`)에 **같은 목록**을 띄운다. 그리는 함수를
하나만 두고 둘이 부른다 — 두 벌을 만들면 반드시 갈라진다.

## 4. 무기 — **레이저 · 열추적 · 유도** 셋

지금도 셋이다 (기총 · 열추적탄 · 유도탄, `1`·`2`·`3` 으로 고르고
**Space** 로 쏜다). 없는 것은 **레이저**다.

★ **기총을 레이저로 바꾼다.** 우주에서 실탄 기총은 「쏠법한 것」이
  아니고, 무엇보다 **탄약이 열로 바뀌면 이 배의 열 계통과 맞물린다**:

| | 파는 것 | 산다 |
|---|---|---|
| **레이저** | **열** (탄약이 없다) | 즉발 · 무한 · 대신 쏘면 뜨겁고 **자국이 오른다** |
| **열추적탄** | 미사일 1발 | 쏘고 잊는다 · 대신 가깝고 잘 놓친다 |
| **유도탄** | 미사일 2발 | 멀리 간다 · 대신 끝까지 묶고 있어야 하고 훤히 보인다 |

셋이 **다른 것을 판다** — 승부수와 같은 규칙이다.

## 5. **미사일 저장고** — 재고 · 보급 · 구매

지금 미사일은 **부품**을 쓴다. 그러면 「고치는 것」과 「쏘는 것」이 같은
자원이라 **수리를 못 하게 되는 것이 유일한 벌**이다. 사장님 말씀대로
**따로 뗀다**:

| | 어디 | 어떻게 는다 |
|---|---|---|
| **미사일** `missiles` | **에어록 옆 탄약고** | 거점에서 **광석으로 산다** · 표류선·구조 신호에서 **보급** |

- 최대 **8발**. 열추적 1발 · 유도 2발
- 거점 접수구에서 **광석 → 미사일**로 바꾼다 (지금 광석 → 부품·식량과
  같은 자리, **같은 손잡이**)
- 다 쓰면 **레이저만 남는다** — 레이저는 탄약이 없으므로 **못 쏘는 상황이
  안 생긴다.** 대신 열이 오르고 자국이 난다

★ **탄약고를 방으로 만들지 않는다.** 방이 여덟이 되면 왕복이 길어진다 —
  에어록 벽에 **랙**을 붙이고 거기서 센다 (베이 번호 규약).
