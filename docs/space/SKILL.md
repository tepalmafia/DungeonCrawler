## 0. 먼저 쟀습니다 — 숫자 셋이 기획을 정합니다

**① 손이 이미 꽉 찼습니다.**

`keys-table.js HAND_MAX = 3` — 한 번에 세 키까지가 한계입니다. 지금 손이
하는 일: 쏘기(Space) · 보조(우클릭) · 무기 셋(1·2·3) · 추력 톡/꾹(R) ·
급기동(Shift) · 스로틀(W/S) · 요(A/D) · 롤(Q/E) · 기수(마우스) ·
표적(T·Tab) · 광학(B) · 수리(P) · 회수(F/G).

★★★ **그래서 이 기획의 제일 큰 제약은 「스킬을 몇 개 만드나」가 아니라
「손을 몇 개 더 쓰나」입니다.** 열 개를 만들어도 손이 없으면 아무도 안 씁니다.

**② 사람이 커도 화면이 안 바뀝니다.**

성장의 사람 갈래(`growth-table.js`)는 특성 **아홉 개**인데 **전부 수동
보정**입니다 — 정중앙 띠 +7% · 회피 창 +0.1초 · 레이저 열 ×0.78 …
맞는 설계지만, **레벨 7에 여섯 번을 골라도 화면에서는 아무 일도 안 납니다.**

★★ 「화려함」이 빈 자리가 정확히 여기입니다. `genre-table.js` 가 RPG 의
기둥을 **성장** 하나로 잡았는데, 그 성장이 **보이지 않습니다.**

**③ 전투 한 판이 짧습니다.**

| 적 | 맷집 | 레이저만으로 |
|---|---|---|
| 요격기 | 2 | 1.1초 |
| 침입선 | 10 | 5.5초 |
| 포함 | 22 | 12초 |

(레이저 피해 1 · 재장전 0.55초 → 초당 1.8)

★ 그래서 **쿨다운이 60초를 넘으면 한 판에 한 번도 못 씁니다.**
쿨은 **12~30초**가 맞습니다 — 한 교전에 한두 번.

   아닙니다 — 지어 놓은 다섯에 **능동 손잡이**를 하나씩 다는 것입니다

## 3. ★★★ 스킬 다섯 — 각각 **이미 있는 계통**에 물립니다

| | 스킬 | 무엇을 하나 | 값 | 쿨 | 어디에 물리나 |
|---|---|---|---|---|---|
| ① | **기만체** (체프·플레어) | 나를 문 **락온이 풀리고** 날아오던 탄이 빗나간다 | 통 3발 (파밍으로 채움) | 12초 | 락온 v119 · 회피 v135 |
| ② | **전력 몰기** | 무기·기동·센서 **하나에 몰아준다** (계속) | 나머지 둘이 약해진다 · 전환 1.5초 | — | 차단기·열 v58 |
| ③ | **관성 정지** (드리프트) | **속도는 그대로, 기수만 홱 돈다** | 추진제 크게 · 도는 1.2초 동안 못 쏨 | 18초 | 비행 v73 · 속도감 v144 |
| ④ | **과부하** | 다음 **3초** 레이저 피해 ×3 | 열이 폭증 — 끝나면 **과열** | 25초 | 열 v58 · 레이저 |
| ⑤ | **EMP 방출** | 반경 안의 적이 **4초** 못 쏘고 못 돈다 | **내 계기도 2초 꺼진다** | 30초 | 정전 (장면 E) |

### 왜 이 다섯인가 — 하나씩

**① 기만체** — 지금 **쫓기는 것에 대해 할 수 있는 일이 「피한다」뿐**입니다
(v135 회피). 락온을 **떼어 내는** 길이 하나 더 생기면, 「맞기 전에 꺾는다」와
「물리기 전에 턴다」가 갈립니다. 그리고 통이 3발이라 **언제 쓰나**가 결심이 됩니다.
★ 화면: 은박이 뒤로 흩날리며 반짝이고, 쫓던 탄이 그쪽으로 휜다.

**② 전력 몰기** — 벤치마크 넷 중 넷이 씁니다. 이 배는 이미 차단기로
**전력을 나누고** 있으므로(v58) 자리가 있습니다. 무기에 몰면 레이저 열이
덜 오르고, 기동에 몰면 급기동이 빨라지고, 센서에 몰면 레이더가 멀리 봅니다.
★★ **쿨이 없습니다** — 대신 **늘 하나만** 고를 수 있습니다. 그게 값입니다.
★ 화면: 계기 막대가 옮겨 붙고 창 테두리 색이 바뀐다.

**③ 관성 정지** — **제일 「우주다운」 기동**입니다. 공기가 없으니 기수와
진행 방향이 따로 놉니다. 뒤를 잡힌 상태에서 **기수만 돌려 쏘고 다시 도망**갈
수 있고, 그러면 v137 의 어스펙트(뒤가 아프다)가 **양쪽으로** 성립합니다.
★★ 1.2초 동안 못 쏘는 것이 값입니다 — 공짜면 늘 이 상태로 다닙니다.
★ 화면: 별이 옆으로 흐르는데 기수는 딴 데를 본다. v144 의 속도감이 그대로 산다.

**④ 과부하** — 레이저는 **탄이 무한이고 열이 값**입니다(v141). 그 저울을
**잠깐 크게 기울이는** 것이 이 스킬입니다. 3초 동안 포함(맷집 22)을
12초 → 5초에 깎지만, 끝나면 **과열이라 한동안 못 숨습니다**(자국이 오름).
★ 화면: 총열이 하얗게 달아오르고 빔이 굵어진다.

**⑤ EMP 방출** — 「내 계기도 꺼진다」가 **이미 만들어져 있습니다** (장면 E ·
정전). 그러니 새로 지을 것이 거의 없고, **양날**이 저절로 섭니다: 적을 4초
멈추는 대신 나도 2초 눈을 감습니다. 여러 대에 둘러싸였을 때만 이득입니다.
★ 화면: 푸른 고리가 퍼져 나가고 적 엔진 불이 꺼진다.

## 4. ★★★ 손에 어떻게 넣나 — **키를 하나만 늘립니다**

★★★ **여기를 쓰면서 §9-① 을 먼저 돌렸고, 그 자리에서 걸렸습니다.**
처음에 「Z 와 V 를 쓰자」고 적었는데 **둘 다 이미 씁니다**:

| 키 | 이미 하는 일 |
|---|---|
| **Z** | 광학 창 크게/닫기 (v141) |
| **V** | 탄두 투하 (v93) |

★★ 이게 **기획을 재는 것에서 시작하는 이유**입니다. 안 재고 넘어갔으면
숫자를 다 정한 뒤에야 「손이 거기 못 간다」를 알았을 것이고, 그건 v110 이
「WASD 로 걷습니다」로 겪은 것과 같은 모양입니다.

**정말 비어 있는 키** (`main.js` · `keys-table.js` 를 통째로 세어 봤습니다):

```
   KeyO · Digit4 · Digit5 · ControlLeft   ← 넷뿐입니다
```

그래서 배치를 이렇게 잡습니다:

```
   장착 슬롯 둘   →  4 (①슬롯) · 5 (②슬롯)
   전력 몰기      →  Ctrl + 1/2/3 (무기 · 기동 · 센서)
```

- ★★ **4·5 가 1·2·3(무기 고르기) 바로 옆**입니다. 같은 손가락 줄에 있으므로
  「숫자열은 고르는 자리」라는 규칙이 하나로 유지됩니다 — 새 규칙을 안 만듭니다
- 다섯 중 **둘만 장착**합니다. 나머지 셋은 **못 씁니다**
- ★★★ 그 「둘 고르기」가 **성장의 결심**입니다 — 지금 성장이 수동뿐이라
  화면에 안 보이던 그 자리를 이것이 메웁니다
- 전력 몰기는 **지속**이라 슬롯을 안 먹습니다. 대신 `Ctrl` 조합이라 급할 때
  못 바꿉니다 — 그것이 「미리 정해 두는 것」이라는 뜻입니다

★ 남는 키가 **`KeyO` 하나**뿐이 됩니다. 다음에 새 조작을 만들 때는
**무엇을 접을지부터** 정해야 합니다 (가르침이 일곱으로 못박힌 것과 같은 규약).

## 6. 화면 — 「화려하다」의 뜻을 못박습니다

★★★ **화려함은 「밝고 큰 것」이 아니라 「무슨 일이 났는지 한눈에 읽히는
것」입니다.** v87 에 속도감을 주려고 알갱이를 키웠다가 **쫓던 적이 그 뒤로
사라진** 적이 있습니다. 그래서 규칙 셋:

1. **창밖 복판을 안 덮는다** — 전투 원뿔(0.45) 밖에서 논다
2. **0.6초 안에 끝난다** — 그보다 길면 조작을 가린다 (EMP 고리만 예외)
3. **소리는 선체를 때린 것만** — 진공 규칙(v74)을 안 어긴다.
   EMP·기만체는 **내 배에서 나가는 것**이라 들린다

## 7. 표에 넣을 숫자 — **기획이 끝났다는 뜻**

`web/space/js/game/skill-table.js` (three 안 씀):

```
SKILLS = [
  { key:'chaff',   name:'기만체',   slot:true,  ammo:3, cool:12, sec:0,   opens:2 },
  { key:'pips',    name:'전력 몰기', slot:false, swap:1.5, gain:0.35, lose:0.2, opens:3 },
  { key:'drift',   name:'관성 정지', slot:true,  cool:18, sec:1.2, fuel:14, opens:4 },
  { key:'overdrive',name:'과부하',  slot:true,  cool:25, sec:3,   dmg:3, heat:38, opens:6 },
  { key:'emp',     name:'EMP',      slot:true,  cool:30, sec:4,   blind:2, r:120, opens:7 },
]
SLOTS = 2            // 다섯 중 둘만
FX = { maxSec:0.6, cone:0.45 }   // 화면 규칙 (§6)
```

**`tools/space-skill.js` 가 묻는 일곱**

1. **손이 안 넘치나** — 새 키가 둘 이하인가 · 이미 쓰는 키와 안 겹치나
2. ★★★ **겨누는 것을 대신하지 않나** — 스킬만으로 적이 죽는 길이 있나
3. ★★★ **다 못 가지나** — 다섯 중 둘. 레벨 7에 전부 열리면 결심이 없다
4. **전부 값을 치르나** — 열·추진제·탄·시간 중 하나가 반드시 든다
5. ★★ **쿨이 전투 한 판 안에 있나** — 12~30초 (한 판이 5~12초 × 여러 마리)
6. ★★ **화면을 안 가리나** — 효과가 전투 원뿔 밖 · 0.6초 안
7. ★★★ **이미 있는 계통에 물렸나** — 다섯이 각각 v58·v73·v119·v135·장면E
   중 하나를 가리키나. 아무것도 안 가리키면 그건 **새 계통을 하나 더 얹은 것**이다
