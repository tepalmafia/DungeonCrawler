# 이미지 규격서

게임에 필요한 그림의 **목록과 규격**.

---

## 공통 규격

| 항목 | 값 |
|---|---|
| 형식 | PNG |
| 배경 | 캐릭터·아이콘·장식 = **완전 투명** / 타일 = 꽉 참 |
| 시점 | **위에서 50° 내려다본 각** (모든 캐릭터·장식 동일) |
| 그림자 | **그리지 않음** — 게임이 바닥에 따로 깔음 |
| 조명 | 위에서 평평하게. 강한 명암·역광 없음 |
| 좌우 | 캐릭터는 **비대칭 장식 없음** (서쪽 방향은 좌우 반전으로 생성) |
| 타일 | **이어 붙을 것(seamless tileable)** — 좌우 끝·상하 끝이 맞물림 |
| 캐릭터 발 위치 | **모든 프레임에서 동일** (발바닥 높이·가로 위치) |

## 3. 캐릭터 스프라이트

### 등장인물

| 이름 | 파일 접두 | 크기 | 내용 |
|---|---|---|---|
| 기사 (플레이어) | `knight` | 256×256 | 은백색 판금 갑옷, 청보라 겉옷과 방패, 금색 테두리, 갈색 단발, 한손검 |
| 오크 | `orc` | 256×256 | 초록 피부, 근육질, 웃통 벗고 갈색 허리띠, 검은 머리, 아래 송곳니, 붉은 눈, 손도끼 |
| 오크 궁수 | `orcarcher` | 256×256 | 같은 초록 오크, 가벼운 가죽 갑옷, 나무 활, 화살통 |
| 구울 | `ghoul` | 256×256 | 창백한 회갈색 시체, 대머리, 움푹한 눈, 벌어진 입과 이빨, 마른 몸, 넝마, 핏자국 |
| 골렘 | `golem` | 384×384 | 사암색 거대한 돌 거인, 두꺼운 팔다리, 큰 주먹, 금 간 자국, 표정 없음 |
| 보스 · 심연의 군주 | `lord` | 512×512 | 크고 떠 있는 존재, 긴 낫, 어두운 옷자락 |

### 방향 — 5방향

`s` 남(정면) · `se` 남동 · `e` 동(옆) · `ne` 북동 · `n` 북(뒤)

> 서 · 남서 · 북서는 좌우 반전으로 만듦. 그래서 5방향이면 8방향이 됨.

### 동작과 프레임 — 캐릭터당 120장

| 동작 | 키 | 한 방향당 | 5방향 합 |
|---|---|---|---|
| 대기 | `idle` | 4 | 20 |
| 걷기 | `walk` | 6 | 30 |
| 공격 | `attack` | 6 | 30 |
| 피격 | `hit` | 2 | 10 |
| 죽음 | `die` | 6 | 30 |
| | | | **120** |

### 파일 이름

```
<캐릭터>_<동작>_<방향>_<번호>.png

knight_idle_s_0.png
knight_walk_se_3.png
golem_attack_n_5.png
```

### 시트로 줄 경우

가로 = 프레임, 세로 = 방향(`s` `se` `e` `ne` `n` 순). **칸 크기 일정.**

```
knight_walk.png  = 6칸 × 5줄 × 256px = 1536 × 1280
golem_attack.png = 6칸 × 5줄 × 384px = 2304 × 1920
```
