# 이미지 기획안 · 설명서

**사장님이 그림을 만드시고, 저는 그것을 게임에 넣습니다.** 제가 만들지 않습니다.
(이 원칙은 `CLAUDE.md` 에 못 박아 뒀습니다 — 다음 세션에도 유지됩니다.)

이 문서 하나만 보시면 **무엇을 · 몇 장 · 어떤 규격으로** 만들지 다 나옵니다.
각 항목에 **생성기에 그대로 넣을 수 있는 설명문**을 같이 적었습니다.

---

## 0. 먼저 읽어 주세요 — 실패하는 다섯 가지

여기서 어긋나면 **그림이 아무리 좋아도 게임에 못 넣습니다.** 만들기 전에 확인해 주세요.

| 실패 | 무슨 일이 나는가 | 어떻게 |
|---|---|---|
| **배경이 안 투명함** | 던전 위에 네모난 판이 뜹니다 | PNG · 알파 채널 · 배경 완전 투명 |
| **그림자가 그려져 있음** | 횃불 밑에서도 그 그림자가 남아 방향이 틀립니다 | 그림자·바닥 반사 **그리지 마세요.** 게임이 깔아 줍니다 |
| **장마다 발 위치가 다름** | 걸을 때 캐릭터가 **위아래로 튑니다.** 제일 흔한 사고입니다 | 모든 장에서 **발바닥이 같은 높이·같은 가로 위치** |
| **바닥·벽이 안 이어짐** | 바닥 전체에 격자선이 보입니다 | 「seamless tileable」로 생성 |
| **각도가 제각각** | 캐릭터가 바닥에 안 붙고 떠 보입니다 | **위에서 50° 내려다본 각**으로 통일 |

> **카메라 각도 50°** 는 이 게임 카메라의 고정값입니다(정확히는 52°).
> 생성기에는 `high-angle view, looking down about 50 degrees, isometric-ish`
> 정도로 넣으시면 됩니다. 정면(0°)이나 완전 위(90°)면 안 맞습니다.

## 1순위 — 던전 타일 **9장** (이게 제일 급합니다)

화면에서 캐릭터는 90픽셀, **전체의 2%** 입니다. 나머지 **98%가 바닥과 벽**입니다.
제가 다섯 판 동안 캐릭터만 고쳐서 화면이 안 바뀐 이유가 이것입니다.

### 규격

- **512 × 512** PNG
- **이어 붙어야 함(seamless)** — 좌우 끝, 상하 끝이 맞물릴 것
- 배경 투명 필요 **없음** (꽉 찬 그림)
- **평평하게 · 그림자 없이.** 밝기 차이는 얕은 요철 정도만
- 색은 아래 지정색 근처로 (게임의 층 테마와 맞물립니다)

### 목록

## 2순위 — 캐릭터 스프라이트

**기사 한 명만 먼저** 주세요. 규격이 맞는지 확인하고 나서 나머지를 가야
합니다 — 다섯을 다 만드시고 규격이 틀리면 전부 다시입니다.

### 등장인물 다섯 (주신 「어둠의 던전」 기준)

| 이름 | 설명 (생성기에 넣을 것) |
|---|---|
| **기사** (플레이어) | 은백색 판금 갑옷, 청보라 겉옷과 방패, 금색 테두리, 갈색 단발, 한손검. 늠름하고 단단한 인상 |
| **오크** | 초록 피부, 근육질, 웃통 벗고 갈색 허리띠, 검은 머리, 아래 송곳니, 붉은 눈, 손도끼 |
| **오크 궁수** | 같은 초록 오크, 가벼운 가죽 갑옷, 나무 활과 화살통 |
| **구울** | 창백한 회갈색 시체, 대머리, 움푹한 눈, 벌어진 입과 이빨, 마른 몸, 허리에 넝마, 핏자국 |
| **골렘** | 사암색 거대한 돌 거인, 두꺼운 팔다리, 큰 주먹, 몸에 금 간 자국, 표정 없음 |

### 규격

| 항목 | 값 |
|---|---|
| 크기 | **256 × 256** (골렘만 384 × 384) |
| 형식 | PNG · **배경 완전 투명** |
| 각도 | **위에서 50° 내려다본 각** — 전부 동일 |
| 발 위치 | **모든 장에서 같은 자리.** 발바닥이 그림 아래에서 같은 높이 |
| 그림자 | **없음** |
| 조명 | 위에서 평평하게. 강한 명암 넣지 마세요 |
| 좌우 | **비대칭 장식 피해 주세요** — 서쪽 방향은 제가 뒤집어 씁니다 |

### 방향 — **5방향만**

`s`(남·정면) · `se`(남동) · `e`(동·옆) · `ne`(북동) · `n`(북·뒤)

서·남서·북서는 제가 좌우 반전해서 만듭니다. 그래서 **5방향이면 8방향이 됩니다.**

### 동작과 장수 — 캐릭터 하나에 **120장**

| 동작 | 한 방향당 | 5방향 |
|---|---|---|
| 대기 `idle` | 4 | 20 |
| 걷기 `walk` | 6 | 30 |
| 공격 `attack` | 6 | 30 |
| 피격 `hit` | 2 | 10 |
| 죽음 `die` | 6 | 30 |
| | | **120장** |

### 파일 이름

```
knight_idle_s_0.png     knight_idle_s_1.png   ...
knight_walk_se_0.png    ...
knight_attack_e_0.png   ...

캐릭터: knight  orc  orcarcher  ghoul  golem
동작:   idle  walk  attack  hit  die
방향:   s  se  e  ne  n
```

> **한 장짜리 시트로 주셔도 됩니다.** 가로가 프레임, 세로가 방향인 격자면
> 제가 잘라 씁니다. 그때는 **칸 크기가 정확히 일정**해야 합니다
> (예: `knight_walk.png` = 가로 6칸 × 세로 5줄, 각 칸 256×256 = 1536×1280).
> 시트 쪽이 발 위치를 맞추기 더 쉬워서 **이쪽을 권합니다.**

## 넘겨주시는 방법

- 압축 파일 하나로 주시면 제일 좋습니다 (폴더 구조는 자유)
- 규격이 안 맞아도 **일단 주세요.** 제가 보고 무엇이 왜 안 맞는지 말씀드립니다
- 시험 삼아 **기사 `idle` 5장(방향별 1장)만** 먼저 주시는 것도 좋습니다 —
  그것만으로 게임에 세워서 크기·각도가 맞는지 확인해 드릴 수 있습니다

그림이 오면 통째로 걷어냅니다 — 더 다듬는 데 시간을 쓰지 않겠습니다.
